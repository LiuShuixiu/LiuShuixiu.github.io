# 前言

各位别再推荐PT了。PT门槛高，需要保持长期的站点活跃度和健康的分享率——说白了就是得整天开着电脑保持上传，费电费时费力。而且PT上那些独家资源，99.9%都会通过BT或网盘分流出去。

# BT资源网站

# 1. 片源网 ⭐ 推荐指数：⭐⭐⭐⭐⭐

特点

  • 完全免费，无需注册即可查看磁力链接
  • 整合全网国内外各发布小组的BT资源
  • 按分辨率分类，使用便捷

缺点

  • 仅是收集整合网站，已关闭注册
  • 无"找回密码"功能，忘密码即无法使用

# 2. 4KSJA

网址：http://www.4ksj.com

特点

  • 论坛型网站，有BT也有网盘
  • 门槛较低
  • 每天签到可获得论坛币

成本

  • 需要回复才能下载
  • 下载种子需要花费论坛币
  • 可购买论坛币（或每日签到获取）

优势

  • 该网站收费资源在片源网都有免费版本
  • 门槛已经算够低

# 3. 银粉们

网址：https://www.yinfans.net/

特点

  • 又一个BT整合网站
  • 完全免费

缺点

  • 更新速度较慢

# 4. BBQDDQ / BaiduBaidu

网址：

  • www.BBQDDQ.com
  • http://10001.baidubaidu.win

特点

  • 高质量资源，最低分辨率1080P
  • 全网资源发布源头，被多个网站转载
  • 拥有自己的种子服务器

成本

  • 永久会员买断制：399元一次性
  • 适合不差钱的用户

备注

  • 发布的资源很快会被整合到片源网等其他网站

# 免费网盘分享网站

# 123网盘

网址：

  • https://time.123in.link/
  • https://123.panbox.my/

# 天翼网盘 ⭐ 推荐

网址：

  • https://hmxz.org/
  • https://leijing1.com/
  • https://jinglei.eu.org/

特点

  • 免费，只需注册并回复
  • 非会员速度与会员无异，几乎满速
  • 个人最喜欢，资源丰富

用途

  • 某些较旧的BT无法下载时的替代方案
  • 寻找冷门资源

缺点

  • 某些热门大IP电影资源会被和谐

# 1Lou.me

网址：https://www.1lou.me/

特点

  • 完全免费，无需回复
  • 有BT也有网盘（网盘支持夸克、部分百度网盘）
  • 几乎无门槛，小大体积版本都有
  • 适合要求不高的用户

注意

  • ⚠️ 某些浏览器无法打开，需自己测试
  • 实测：搜狗浏览器无法打开，但115浏览器可以
  • 资源相对混乱，需要自己搜索摸索

推荐指数：适合新手

# NAS大户资源库 🔥

描述：资源库超级完整，请务必收藏

网址：https://pan.quark.cn/s/c3333a74b59c#/list/share

特点

  • 主人一直在更新资源
  • 资源质量和数量惊人
